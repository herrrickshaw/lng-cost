# Reference leads for calibration

**Status: leads from a web search, not yet read or verified.** No figure in this
repository is taken from them. Open each, confirm licence/access, then calibrate
`capex.py` quantities (steel t, concrete m3, labour hours, equipment USD per reference
plant) and the default prices against the cited values.

| Network LP model | Chem. Prod. Process Model. 2025, doi:10.1515/cppm-2025-0017 |
| Estimate classes | AACE International recommended practices (check original, not blogs) |

Commodity and labour inputs (steel, cement, wages, equipment indices) should come from
public series you can cite, e.g. national statistics, World Bank Pink Sheet, ENR/CEPCI
if licensed. Do not commit proprietary subscription data to this public repo.
